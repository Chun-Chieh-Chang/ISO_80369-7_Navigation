# 使用指南 — ISO 80369-7 / ISO 80369-20 導航系統

本文說明三個功能域的分工、兩層圖表檢視模式的差異，以及各使用場景該走哪條路徑。

---

## 1. 三個功能域（互不重疊）

| 功能域 | 回答的問題 | 進入點 |
|---|---|---|
| 🔍 **規範探索中心** | 「這個測試主題的完整法規要求是什麼？」 | 主題條文導覽 / 知識關聯圖譜 |
| ⚖️ **條文橫向對照** | 「ISO 80369-7 條文與 ISO 80369-20 測試方法怎麼對應？」 | 雙標準對照矩陣 |
| 🛠️ **驗證工程工作台** | 「我要出一份可交付主管機關的 DVP 報告」 | 夾具庫與力學檢驗 / DVP 驗證與報告匯出 |

三者服務不同工作，不是同一件事的三個入口。

---

## 2. 兩層圖表檢視模式

規範圖解只有兩種檢視深度，標記固定：

| 層級 | 標記 | 位置 | 內容 | 適用場景 |
|---|---|---|---|---|
| Tier 1 | 🖼️ **快速預覽** | 對照矩陣列內展開 | 僅規範圖解 | 對照表格時想順手看一眼圖 |
| Tier 2 | 📖 **完整規格** | 條文深度規格抽屜 | 圖解 + 定量參數 + 測試步驟 + 允收標準 + 常見不符合 | 撰寫規格、查數值、準備稽核 |

**兩者是階梯，不是兩扇並排的門。** 對照矩陣每一列同時提供 🖼️ 與 📖：先預覽，需要細節時就地按 📖 展開同一份深度規格抽屜——不必切換到探索中心再找一次。

> 標記選用說明：⚡ 在本系統已代表「機械強度」分類、🔬 已代表「ISO 80369-20」，故層級標記改用未被佔用的 🖼️（圖面本身）與 📖（讀完整規格）。

### 不是圖表檢視器的三個畫面

以下畫面也會顯示圖，但工作性質不同，**不套用層級標記**：

- **知識關聯圖譜** — 條文之間的關聯導覽（節點／連線）
- **參考金屬夾具庫** — Annex B/C 夾具型錄與選型
- **DVP 驗證與報告匯出** — 驗證報告產出

## 3. 使用場景推薦

| 你想做的事 | 建議路徑 |
|---|---|
| 查某個測試的法定數值（壓力／拉力／扭矩／持壓時間） | 對照矩陣 → 該列 **📖 完整規格** |
| 確認某條文該配哪一支 Annex C 金屬參考夾具 | 對照矩陣「必要金屬參考夾具」欄，或 DVP 工作台選定公母／鎖滑後自動帶出 |
| 了解某主題橫跨哪些條文與附錄 | 規範探索中心 → 主題卡片 → **📖 完整規格**（抽屜頂端列出連動條文頁籤） |
| 看條文之間的關聯脈絡 | 規範探索中心 → 知識關聯圖譜 |
| 比較 ISO 80369-7 要求 vs ISO 80369-20 方法 | 條文橫向對照矩陣 |
| 查夾具的實際 CAD 尺寸與最壞情況理由 | 驗證工程工作台 → 夾具庫與力學檢驗 |
| 產出可交付的驗證報告 | 驗證工程工作台 → DVP 驗證與報告匯出 → Excel / CSV |

## 4. 資料來源與單一真實來源（SSOT）

| 資料 | 唯一來源 | 說明 |
|---|---|---|
| 條文定量參數 | `src/data/isoData.ts` → `ISO_CLAUSES` | 直接對應 ISO 80369-7:2021 Clause 6 |
| Annex C 夾具身分與適用條文 | `src/data/isoData.ts` → `ANNEX_C_FIGURES` | 逐字對應 Annex C 各圖標題 |
| 夾具配對邏輯 | `src/utils/isoHelpers.ts` → `getRequiredReferenceConnector()` | 由 `ANNEX_C_FIGURES` 推導；矩陣、抽屜、Excel 匯出共用同一函式 |
| 標準預裝配程序 | `src/utils/isoHelpers.ts` → `getPreAssemblySpec()` | 鎖定型與滑動型序列不同，見下節 |
| 圖表層級標籤 | `src/i18n/translations.ts` → `figureTier` | 跨元件唯一定義 |

夾具配對規則：受測件一律配**相反性別**、**相同鎖／滑型式**的參考接頭。

| 條文 | 允許的參考接頭（ISO 80369-7:2021） |
|---|---|
| 6.1.2 / 6.1.3 / 6.2 / 6.3 | Fig. C.1、C.2、C.4、C.5 |
| 6.4 | Fig. C.2、C.3、C.5、C.6 |
| 6.5（僅鎖定型） | Fig. C.1、C.4 |
| 6.6（僅鎖定型） | Fig. C.3、C.6 |

## 5. 引用與版本注意事項

1. **定版引用**：ISO 80369-7:2021 Clause 2 以定版方式引用 **ISO 80369-20:2015**（定版引用僅該版適用）。本系統呈現 **ISO 80369-20:2024**；Annex B~H 與所有定量測試參數兩版一致，2024 版另增 Annex I / J / K。撰寫報告時請依實際採用版本引用。
2. **附錄性質**：ISO 80369-20:2024 的 Annex B~K 標示為 *informative*（參考性）。強制力來自 ISO 80369-7:2021 Clause 6 的 “Check conformance by applying the tests of ISO 80369-20, Annex X”。
3. **測試報告項數不一致**：常被引用的「14 項 (a~n)」只屬於 **Annex B.5**。各附錄實際要求：

   | Annex | B | C | D | E | F | G | H | I | K |
   |---|---|---|---|---|---|---|---|---|---|
   | 項數 | 14 | 12 | 13 | 12 | 10 | 11 | 12 | 11 | 13 |
   | 編號 | a~n | a~l | a~m | a~l | a~j | a~k | a~l | a~k | a~m |

   其中 k)「測試容積（Figure B.1）」與 m)「壓力變化量（B.4 f）」**僅 Annex B 要求**。系統內建清單以 Annex B.5 為超集檢核表。
4. **預裝配程序因型式而異**（ISO 80369-20:2024, X.4 b）：
   - **鎖定型**：先將套環旋至 0.08–0.12 N·m 扭矩 → 再施加軸向推力 26.5–27.5 N → 維持 5–6 秒後釋放
   - **滑動型**：先施加軸向推力 26.5–27.5 N → 再以 **≤ 0.10 N·m** 扭矩旋轉 **≤ 90°** → 維持 5–6 秒後釋放

   兩者順序相反，滑動型是「限扭矩、限角度」而非定值扭矩。
5. **預處理條件**出自各測試附錄的 X.2.1 / X.2.2（(20 ± 5) °C、(50 ± 10) % RH、≥ 24 h；測試環境 15–30 °C、10–70 % RH），非 Clause 4、亦非 Annex A。

## 6. 一致性防護

`src/utils/isoConformance.test.ts` 將上述標準事實寫成測試：條文定量值、Annex C 六張圖的性別／型式／適用條文／最壞情況旗標、夾具配對不得越出標準允許集合、預裝配雙序列、各附錄報告項數、以及對照矩陣每一列都能開啟深度規格抽屜。資料若偏離標準，`npm test` 會失敗。

```bash
npm test
```
