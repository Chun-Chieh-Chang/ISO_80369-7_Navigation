# Workspace Agent Rules

## 1. 專案整體程式碼與檔案優化作業觸發協定 (Codebase Cleanup & Optimization Protocol)
當用戶輸入觸發咒語：「**執行專案的整體程式碼與檔案優化作業**」時，必須立刻自動調用 `codebase-cleanup-optimization` Skill 並嚴格執行以下 5 大閉環 SOP：

1. **全面盤點與清理作業**：遍歷專案所有目錄與檔案，識別並移除過時、冗餘、無效的程式碼片段與獨立檔案（含棄用模組、未引用資源檔、重複邏輯及失效配置），過程確保現有功能正常運作。
2. **同步更新所有開發相關文件**：全面檢視 `DEV_LOG.md`、專案 Wiki 等所有開發文件，同步更新至最新功能狀態，補充新增功能說明、調整架構描述、更新版本記錄、修正過時操作指引，確保文件與程式碼完全一致。
3. **遵循 MECE 原則整合整理**：以相互獨立、完全窮盡 (MECE) 的分類邏輯整合剩餘有效資源，統一檔案存放結構與程式碼格式，梳理模組間依賴關係，消除分類模糊或重疊配置。
4. **建立程式碼還原基準點**：透過 Git 提交本次所有變更，編寫清晰規範的 Commit 訊息，說明清理、更新與整合的具體內容，建立可追溯、可還原的版本基準。
5. **推送變更至 GitHub 遠端倉庫**：確認無數據隱私與敏感資訊問題且本地提交無誤後，將變更推送至 GitHub 對應分支，完成部署流程。
